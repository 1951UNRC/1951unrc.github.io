# 1951unrc.github.io

An independent, English-language reference site about misunderstood parts of
the 1951 UN Refugee Convention, starting with “Article 31 explained”.
Article content is coming soon.

The site uses plain HTML and a shared CSS file, with no JavaScript, dependencies,
or build step. Open `index.html` in a browser, or run `python3 -m http.server 8000`
from the repository directory and visit <http://localhost:8000>.

To add a guide, create an HTML page using the existing article page as a template
and add its link to the article list in `index.html`.
